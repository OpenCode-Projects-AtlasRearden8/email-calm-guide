# Common mistakes

Nobody avoids all of these — you'll recognize a few because you've tried them, and that's fine; every one of these is a normal thing tired humans do with email. This page is simply the short trip past each one.

## The big table

| The mistake | What's behind it | The gentler fix |
|---|---|---|
| Treating the inbox as the to-do list | It's the fastest single place that already exists | Three folders (ch. 2): Needs action *is* your to-do list, and the inbox stays a landing strip |
| Reading an email five times without deciding | Deciding is the expensive part | Decide on first contact: reply, move, or archive. "Read again later" is not one of the options |
| Forty-seven folders | Filing feels like tidiness | Three folders + search. If it needs a second home, it's a rule's job, not yours |
| Guilt-subscribing ("it's a good cause") | The cause stays good; the email still never gets read | Three-strikes rule (ch. 4). Support causes directly; unsubscribe from the newsletter |
| Replying long to prove effort | Length feels like sincerity | Three sentences + a date. What people remember is the answer, not the word count |
| Checking email all day "in case" | Open loops (ch. 1) make the inbox feel alive | Ten-minute window + notifications off. Nothing is on fire that you'd see sooner that way |
| Snoozing into oblivion | Snooze postpones the *decision*, not the work | Snooze = archive + future date you'd actually act. If there's no such date, it's a no |
| Saving every email forever "just in case" | Storage anxiety | Search finds things by words, names, dates. Keep nothing you can't explain keeping |
| Seamlessly skipping the weekly reset | It wasn't anchored in the calendar | Treat the reset as a standing appointment (ch. 10); skip weeks freely, keep the habit |
| Sending an AI draft unread | The tool is confident *and* sometimes wrong | Read before send; AI drafts are drafts (ch. 7) |
| Asking someone else's opinion instead of deciding | Failing alone is scary; sharing is slower | Decide within the tidy; ask only when the decision is genuinely theirs |

## The pattern worth noticing

Look down that list: almost every mistake is a version of **deciding later**. Later-decisions cost more each time — more context lost, more re-reading, more dread compounding. Every chapter of this manual is some flavor of "decide once, cheaply, now".

And the meta-mistake behind the meta-mistake: believing the calm comes from *more discipline*. Every fix in the table above is smaller than the mistake it replaces. Calm email is small habits and fewer places to look, which is good news if "more discipline" was never in stock.

> **If you only do one thing:** pick the row you flinch at most and do its gentle fix exactly once this week. One row per week quietly beats overhauling everything on Sunday and quitting by Thursday.
